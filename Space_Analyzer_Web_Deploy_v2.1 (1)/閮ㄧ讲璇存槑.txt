部署方式：
1. 解压本压缩包。
2. 将 index.html 和 src 文件夹作为同级项目上传到网站同一个目录。
3. 不要只上传 index.html；不要把 src 文件夹改名；不要把 src 再套入另一层目录。
4. 打开网站后，先点击左侧导航和“切换外观”检查交互，再点击“选择扫描位置”。
5. 浏览器版只能读取用户主动选择/授权的目录。建议使用 HTTPS 或 localhost；若浏览器不支持目录授权，会退回系统文件夹选择控件。

注意：如果网站启用了严格的 Content-Security-Policy，请允许同源脚本和样式加载。本包使用普通相对路径脚本，不依赖 ES module 或 .mjs MIME 类型。
